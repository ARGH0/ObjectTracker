Current constraint

Vision Pipeline Inclusion does not mean simultaneous Train State processing. The implementation processes one selected Camera Source.

Problem. Operator-facing Camera Workspace can show many included Camera Sources, but the Vision Pipeline has one active Camera Source.

Solution. Keep the single-selected-camera seam explicit in every debug and settings decision.

  • locality: active camera
  • interface: one preview stream
  • depth: processing absorbs frames
ADR callout: ADR 0004 preserves current Vision Pipeline Inclusion semantics.
