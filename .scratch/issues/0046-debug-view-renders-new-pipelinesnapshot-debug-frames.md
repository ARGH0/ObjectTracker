## Agent Brief

**Category:** bug

**Summary:** Debug View should render the Debug Frames currently emitted by `PipelineSnapshot` instead of relying on legacy debug-frame names.

**Current behavior:**

When Debug View is enabled for a visible Camera Source included in the running Vision Pipeline, the UI is expected to show Debug Frames from the same `PipelineSnapshot` flow as LiveAnnotated. After the snapshot migration, the Vision Pipeline emits named Debug Frames using snapshot-domain names such as `source`, `moving-object-observation`, `train-observation`, and `train-tracking`. The UI debug tile still appears to route primarily by old background-estimation/preview names, so the new Debug Frames do not populate the Debug View correctly.

**Desired behavior:**

When a visible included Camera Source is in Debug View while the Vision Pipeline is running, every available `PipelineSnapshot.DebugFrames` entry should be visible to the operator in a stable, understandable Debug View presentation. The UI should not silently collapse unknown Debug Frame names into one quadrant, hide frames, or leave stale legacy panes that make Debug View look broken. Debug View should still work when only a subset of Debug Frames is present.

**Key interfaces:**

- `PipelineSnapshot.DebugFrames` — the UI-facing collection of named Debug Frames for a Camera Source.
- `DebugFrame.Name` — should drive display labels or slot selection without assuming only the old preview names exist.
- `CameraTileFrameSource.PipelineSnapshotDebugFrames` — the tile route that should display Debug Frames rather than Annotated Frame or raw Camera Source feed.
- Camera tile debug rendering/projection logic — should present Debug Frames from the snapshot seam in a way tests can verify without relying on private UI event wiring.
- Vision Pipeline Debug Frame production — should keep Debug Frames snapshot-domain focused and only emitted when Debug View is enabled for the Camera Source.

**Acceptance criteria:**

- [x] A regression test proves that Debug Frames with the current snapshot-domain names are routed/displayed in Debug View instead of all falling into one legacy fallback pane.
- [x] Debug View handles at least `source`, `moving-object-observation`, `train-observation`, and `train-tracking` Debug Frame names without dropping or overwriting them unexpectedly.
- [x] Debug View remains usable when only some Debug Frames are present for a snapshot.
- [x] LiveAnnotated tiles still render the Annotated Frame from `PipelineSnapshot` when Debug View is disabled.
- [x] Raw Camera Source feed behavior for excluded or stopped visible Camera Sources is unchanged.
- [x] Existing UI and Vision tests pass after the fix.
