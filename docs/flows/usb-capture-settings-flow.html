Current policy

  • Raw tile startup uses stable baseline.
  • Requested settings are operator intent.
  • Active Vision Pipeline source is protected.
  • Failed source needs manual restart.

Problem. Runtime hardware mode and requested operator intent can diverge.

Solution. Keep requested settings, actual status, and restart decisions as separate interfaces.

  • locality: setting policy
  • interface: projection decision
  • depth: store stays simple
ADR callout: settings changes must not invalidate active Train State continuity.
