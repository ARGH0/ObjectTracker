# Grid Overlay Editor In Camera Zone Configuration View

Type: AFK  
Labels: ready-for-agent

## Parent

- .scratch/issues/0009-camera-zone-grid-layering-foundation-prd.md

## What to build

Deliver a Camera Zone configuration view where operators can author layers and grid regions directly over the selected camera view. Include creation, selection, edit, and delete flows for layers and regions, using app-wide grid dimensions.

## Acceptance criteria

- [ ] Operator can create/edit/delete layers and regions for the selected Camera Zone.
- [ ] Region editing is constrained to the configured app-wide grid.
- [ ] Authored edits save and reload through normal application restart.
